# Audience calibration

## Strategy

Start with the learner's decision and current capability, then choose the
technical depth and evidence format.

## Audience and context

Use this before a course, workshop, lab, or video when the audience may include
engineers, evaluators, technical enablement practitioners, or leaders with
different responsibilities.

## Teaching problem

Without calibration, a lesson can be technically correct but unusable: it may
assume tools the learner does not have, explain implementation before purpose,
or measure vocabulary recall instead of the target decision.

## Facilitator move

Declare the learner's starting point, target decision, prerequisites, available
tools, and failure cost. Offer one minimum path and optional depth branches.
Use plain-language definitions for terms such as *evaluator* (a component that
judges evidence against criteria) and *harness* (the surrounding workflow that
runs and records the evaluation).

## Learner evidence

Ask the learner to restate the decision, identify one prerequisite gap, and
choose the smallest exercise that can reduce the most important uncertainty.

## Feedback and adaptation

If the learner can run commands but cannot explain the decision, add context
before adding complexity. If the learner can explain the decision but cannot
produce evidence, add a bounded hands-on step.

## Accessibility

Provide text, visual, and runnable forms of the same concept. Keep the minimum
path usable without live provider credentials or fast network access.

## Responsible-use boundary

Audience signals guide teaching scope; they do not justify inferring a
learner's ability, identity, or performance from sparse behavioral data.

## Verification

Review the learner's decision statement and first artifact against a short
rubric before expanding the path.

## What this does and does not prove

It proves that the path was scoped to a declared audience and decision. It does
not prove that the audience is representative or that every learner will
achieve the same outcome.
