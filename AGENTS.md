# Repository guidance

This is a public teaching-strategies repository.

- Keep examples synthetic or metadata-only.
- Do not add private learner records, unpublished exam material, raw
  production traces, credentials, provider-private prompts, or internal
  project identifiers.
- Keep strategy cards focused on audience, decision, failure mode, facilitator
  move, learner evidence, accessibility, responsible use, verification, and
  limitations.
- Keep implementation details in the course, design-guide, harness, or research
  repository that owns them; link rather than copy.
- Run `python3 scripts/check_strategy_cards.py` before proposing a change.
